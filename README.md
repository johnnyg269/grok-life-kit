# Grok Life kit

Files the Grok Life Grok Bot installs on its own computer at first run: the coaching playbook (`SKILL.md`), chart and dashboard renderers, scoring, medication tracking, fonts and icons.

Install (run by the bot):

```
curl -L https://github.com/johnnyg269/grok-life-kit/archive/refs/heads/main.tar.gz | tar -xz
```

Fonts are SIL Open Font License (see `fonts/`); icons are Lucide (ISC, see `icons/LICENSE.txt`). Sample data and photos are synthetic. Grok Life is not medical advice.
